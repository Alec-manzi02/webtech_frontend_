# Library Management Frontend

## Run the frontend

Open a terminal in this folder and run:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Office save and delete

The office form currently works as a frontend demo. It saves offices in your browser's local storage, so you can add and delete offices without running a backend. The data stays in that browser and is not saved to a server or shared with other devices.
